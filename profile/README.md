# 🪱 Digital Worms

### Friends. Events. Expenses. Memories.

Digital Worms is a social platform for groups of friends to organize events, manage shared expenses, preserve memories, and stay connected.

</div>

---

## About

Digital Worms is being built as a single place for everything that happens inside a group of friends.

Instead of keeping events in one app, expenses in another, photos somewhere else and plans in a group chat, Digital Worms brings all of it together.

The project is currently under active development.

---

## Core Features

- 🎉 Event creation and participant management
- 💸 Shared expenses and expense splitting
- 📸 Photos and videos connected to events
- 🔔 Notifications and activity updates
- 🎵 Music and event playlists
- 👥 User profiles and authentication
- 📅 Group activity planning
- 🧩 Collaborative features for groups of friends

---

## Backend

The backend is being developed primarily in Go with a focus on clean architecture, maintainability and scalability.

### Tech Stack

- Go
- PostgreSQL
- Docker
- REST API
- Git
- Linux

Planned technologies include:

- Redis
- gRPC
- Kafka
- CI/CD
- Kubernetes

---

## Project Vision

Digital Worms is not being developed as a one-off educational project.

The goal is to build a real product that our own group of friends can use and gradually expand with new features.

Future ideas include:

- 💬 Built-in messenger
- 🤖 AI-powered features
- 🎲 Games and group activities
- 🎧 DJ sets and music management
- 📊 Advanced shared budget analytics
- 🗺️ Trips and travel planning

---

## Status

The project architecture, backend services and core product functionality are being designed and implemented.
